# 社区新生儿上门访视 · 黄疸记录与复查随访系统

面向社区护理场景的全栈演示应用：产妇出院后，社区护士上门访视新生儿，记录黄疸、体重、喂养、脐带、大小便与产妇恢复情况；系统按**出生天数 + 黄疸值 + 体重变化 + 喂养次数 + 排便颜色 + 产妇恢复 + 家庭照护能力**综合评估风险，自动生成复查、转诊、母乳指导、电话随访等随访事项并跟踪闭环。家属端可查看护理建议、复查时间与风险说明，补充出生证明/出院小结/喂养记录，发起线上咨询与改约。护士上门现场网络不稳定时，访视先存**本地草稿**，回到社区后在同步中心**幂等补齐**。

**产妇情绪异常关怀**：访视中产妇表达持续哭泣、睡眠差时，护士在同一访视页记录 **EPDS 爱丁堡产后抑郁量表（10 题）**、家属支持、是否有自伤想法与护士建议；系统按评分/自伤风险提示**心理咨询、增加电话回访、转妇保门诊**并生成敏感随访事项。家属端可代述妈妈近况（哭泣/睡眠/支持/紧急担忧），只看到护士准备的**温和提醒**。后续回访追踪情绪变化（好转/持平/加重）与是否接受帮助。**护士记录与家属代述如冲突，两份来源与各自采集时间均保留并高亮**，供心理咨询或妇保门诊判断风险来自照护压力、睡眠不足还是家庭支持不足。敏感内容按**护士 / 社区医生 / 家属**三级权限保护。

## 功能与角色

| 角色 | 功能 |
| --- | --- |
| **护士**（移动端优先） | 工作台（未访视家庭/异常黄疸/**情绪关怀与自伤紧急**/待闭环）、预约管理（改约、标记未开门）、母婴档案（访视/测量/照片/建议/复查/转诊/材料/咨询/**情绪关怀双来源对照**/时间线同档管理）、访视记录表单（实时风险预评估、**EPDS 量表+情绪关怀卡片**、设备故障手工记录、拍照上传）、**情绪关怀中心**（紧急自伤置顶、家属代述待核实、回访追踪、结束关怀）、**离线草稿与同步中心**、随访闭环处理、回复线上咨询 |
| **社区医生** | 随访决策台：按档案聚合待处理事项，综合随访记录决定**复查 / 转诊 / 电话随访 / 母乳指导 / 心理咨询 / 转妇保门诊 / 继续观察**，决策自动转为新的随访事项并跟踪闭环；**只读查看情绪关怀临床信息（EPDS/自伤/归因/建议），护士内部备注不可见** |
| **家属** | 查看护理建议、复查时间、风险说明；上传出生证明/出院小结/喂养记录；发起线上咨询；申请改约；**妈妈情绪关怀：查看社区温和提醒、代述妈妈观察（不展示量表分/自伤等敏感内容）、收到紧急自伤担忧时的热线指引** |

已覆盖的异常场景：家庭临时改约、家属不愿开门（未开门→再次预约事项）、黄疸值接近阈值（按日龄阈值预警）、婴儿体重下降（>7%/>10% 分级）、**产妇情绪低落/持续哭泣/睡眠差（EPDS 9~12 情绪困扰 / ≥13 高分 / 自伤想法紧急）、家属代述与产妇表述冲突（双来源保留）、家属端敏感内容分级脱敏**、社区设备故障（手工记录标记+复测提醒）、家长线上咨询、离线草稿回社区后同步。

## 技术栈

- **前端**：React 18 + TypeScript + Vite，状态管理用 **Zustand**（Pinia 是 Vue 生态的状态库，无法用于 React；Zustand 提供与 Pinia 相同的 define-store 范式，含 localStorage 持久化）。移动优先响应式布局，适配护士上门现场操作。
- **后端**：Node.js + Express，SQLite（better-sqlite3）文件库，首次启动自动建表并写入演示数据。
- **风险引擎**：`server/risk.js` 与 `client/src/risk.ts` 同构——表单实时预评估与服务端落库结论一致；**情绪关怀 EPDS 评分/分级**：`server/mood.js` 与 `client/src/mood.ts` 同构。

## 一键启动（Docker）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

- 单容器交付：多阶段构建前端 → 后端托管静态页 + REST API + SQLite 初始化。
- 数据持久化在命名卷 `nbv-data`（删除容器不丢数据）；删除卷后重启可重置演示数据。
- 国内网络构建可指定镜像源：`NPM_REGISTRY=https://registry.npmmirror.com docker compose up --build`

## 本地开发

```bash
npm run install:all     # 安装 server 与 client 依赖
npm run dev:server      # 终端1：后端 http://localhost:8080（自动建库+种子数据）
npm run dev:client      # 终端2：前端 http://localhost:5173（/api 代理到 8080）
```

生产模式本地运行：`npm run build && npm start`，然后访问 http://localhost:8080 。

## 情绪关怀规则（`server/mood.js`，与 `client/src/mood.ts` 同构）

- **EPDS**：10 题，每题 0~3 分（第 1、2 题正向表述反向计分），总分 0~30。**第 10 题"曾想过要伤害自己"任一阳性频率 → 自伤想法紧急风险**。
- 分级：**≥13 分（或自伤阳性）= 高风险**（自伤→立即 24h 陪伴、移除危险物品、转妇保门诊/心理危机干预；否则心理咨询+妇保门诊+本周加密回访）；**9~12 分 = 情绪困扰**（心理咨询+增加电话回访，1~2 周复评）；**0~8 分 = 常规观察**。
- 情绪结论写入访视风险 flags/建议供护士知情，但**不抬升新生儿黄疸转诊等级**；情绪处置行动（心理咨询/增加电话回访/转妇保门诊）由情绪关怀模块独立生成 `sensitive=1` 随访事项，跟踪闭环，结束关怀时同批闭环。

## 风险判定规则（`server/risk.js`）

- 经皮胆红素按出生日龄分档阈值（µmol/L）：≤1 天 137 / 2 天 205 / 3 天 257 / ≥4 天 291；**达阈值→危急+转诊**，**距阈值 ≤34→接近阈值预警+24~48h 复查**。
- 体重较出生下降 **>10%→危急+转诊+母乳指导**，**>7%→高风险+母乳指导+复测**。
- 喂养 <8 次/日、白陶土色大便（危急转诊）、脐带渗血/化脓、嗜睡、产妇情绪低落/异常、伤口红肿渗液、家庭照护薄弱等均参与分级；设备故障手工记录强制复测提醒。
- 结论输出：风险等级（低/中/高/危急）+ 是否复查/转诊/母乳指导/电话随访 + 自动生成护理建议（家属端可见，护士可修改）。

## 主要 API

`POST /api/auth/login` · `GET /api/dashboard` · `GET/POST /api/appointments`（`/reschedule`、`/no-show`）· `GET /api/archives`（filter: unvisited/jaundice/maternal/**mood**/unclosed）· `GET /api/archives/:id`（含 `mood_records` 按角色脱敏）· `POST /api/visits`（`/assess` 预评估，支持 `mood_care` 情绪关怀载荷）· `POST /api/sync/visits`（离线幂等同步）· `GET /api/followups`（`/close`、`/decide`，决策含心理咨询/转妇保门诊/增加电话回访）· `GET /api/mood/care`（护士/医生关怀中心）· `POST /api/mood/records`（护士记录/核实）· `POST /api/mood/records/:id/followup`（回访追踪）· `POST /api/mood/records/:id/close`（结束关怀）· `POST /api/family/mood-report`（家属代述）· `GET /api/family/overview`（情绪内容按家属角色脱敏）· `POST /api/documents` · `POST /api/consults`（`/reply`）
