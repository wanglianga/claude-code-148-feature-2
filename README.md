# 社区新生儿上门访视 · 黄疸记录与复查随访系统

面向社区护理场景的全栈演示应用：产妇出院后，社区护士上门访视新生儿，记录黄疸、体重、喂养、脐带、大小便与产妇恢复情况；系统按**出生天数 + 黄疸值 + 体重变化 + 喂养次数 + 排便颜色 + 产妇恢复 + 家庭照护能力**综合评估风险，自动生成复查、转诊、母乳指导、电话随访等随访事项并跟踪闭环。家属端可查看护理建议、复查时间与风险说明，补充出生证明/出院小结/喂养记录，发起线上咨询与改约。护士上门现场网络不稳定时，访视先存**本地草稿**，回到社区后在同步中心**幂等补齐**。

新增**产妇情绪异常关怀**：访视中产妇表达持续哭泣、睡眠差时，护士在访视表单开启「产妇情绪关怀（敏感）」记录 **EPDS 量表分、家属支持、自伤想法、风险来源与建议**；社区可安排**心理咨询 / 增加电话回访 / 转妇保门诊**（自动生成敏感随访事项）；家属端只收到**必要提醒**（脱敏），量表分、自伤想法、风险来源与双来源冲突仅护士/社区医生可见；后续回访追踪**情绪变化与是否接受帮助**；家属代填与产妇自述**冲突时双来源并列保留（含采集时间）**，并标注风险来自照护压力、睡眠不足还是家庭支持不足，供心理咨询/妇保门诊研判。

## 功能与角色

| 角色 | 功能 |
| --- | --- |
| **护士**（移动端优先） | 工作台（未访视家庭/异常黄疸/产妇风险/待闭环）、预约管理（改约、标记未开门）、母婴档案（访视/测量/照片/建议/复查/转诊/材料/咨询/时间线同档管理）、访视记录表单（实时风险预评估、设备故障手工记录、拍照上传、**情绪关怀敏感录入**）、**离线草稿与同步中心**、随访闭环处理、回复线上咨询、**情绪关怀建档/安排/回访/闭环** |
| **社区医生** | 随访决策台：按档案聚合待处理事项，综合随访记录决定**复查 / 转诊 / 电话随访 / 母乳指导 / 心理咨询 / 转妇保门诊 / 继续观察**，决策自动转为新的随访事项并跟踪闭环；与护士同等查看情绪关怀敏感记录 |
| **家属** | 查看护理建议、复查时间、风险说明；上传出生证明/出院小结/喂养记录；发起线上咨询；申请改约；**代填产妇情绪/睡眠/照护人手**；仅接收脱敏的社区关怀提醒 |

已覆盖的异常场景：家庭临时改约、家属不愿开门（未开门→再次预约事项）、黄疸值接近阈值（按日龄阈值预警）、婴儿体重下降（>7%/>10% 分级）、**产妇情绪异常（持续哭泣/睡眠差/量表筛查/自伤想法/家属代填冲突）**、社区设备故障（手工记录标记+复测提醒）、家长线上咨询、离线草稿回社区后同步。

## 产妇情绪关怀 · 敏感信息可见范围

| 内容 | 护士 | 社区医生 | 家属端 |
| --- | --- | --- | --- |
| EPDS 量表分、自伤想法、风险来源、关怀建议 | ✅ | ✅ | ❌ |
| 家属代填 vs 产妇自述冲突（双来源+采集时间） | ✅ | ✅ | ❌ |
| 社区安排（心理咨询/增加电话回访/转妇保门诊）与回访追踪 | ✅ | ✅ | 仅必要提醒 |
| 关怀闭环后的敏感记录 | ✅ 保留可查 | ✅ 保留可查 | ❌ 始终脱敏 |

实现方式：情绪关怀记录独立建表（`mood_cares` + `mood_care_logs`），敏感随访事项打 `sensitive` 标记；家属端所有接口在**服务端**过滤敏感字段（不是前端隐藏），家属仅收到 `moodCare` 脱敏提醒对象与本人代填记录。

## 技术栈

- **前端**：React 18 + TypeScript + Vite，状态管理用 **Zustand**（Pinia 是 Vue 生态的状态库，无法用于 React；Zustand 提供与 Pinia 相同的 define-store 范式，含 localStorage 持久化）。移动优先响应式布局，适配护士上门现场操作。
- **后端**：Node.js + Express，SQLite（better-sqlite3）文件库，首次启动自动建表并写入演示数据。
- **风险引擎**：`server/risk.js` 与 `client/src/risk.ts` 同构——表单实时预评估与服务端落库结论一致（含情绪关怀敏感项，敏感明细不进家属可见的 flags/advice）。

## 一键启动（Docker）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

- 单容器交付：多阶段构建前端 → 后端托管静态页 + REST API + SQLite 初始化。
- 数据持久化在命名卷 `nbv-data`（删除容器不丢数据）；删除卷后重启可重置演示数据。
- 国内网络构建可指定镜像源：`NPM_REGISTRY=https://registry.npmmirror.com docker compose up --build`

## 本地开发

```bash
npm run install:all     # 安装 server 与 client 依赖
npm run dev:server      # 终端1：后端 http://localhost:8080（自动建库+种子数据）
npm run dev:client      # 终端2：前端 http://localhost:5173（/api 代理到 8080）
```

生产模式本地运行：`npm run build && npm start`，然后访问 http://localhost:8080 。

## 风险判定规则（`server/risk.js`）

- 经皮胆红素按出生日龄分档阈值（µmol/L）：≤1 天 137 / 2 天 205 / 3 天 257 / ≥4 天 291；**达阈值→危急+转诊**，**距阈值 ≤34→接近阈值预警+24~48h 复查**。
- 体重较出生下降 **>10%→危急+转诊+母乳指导**，**>7%→高风险+母乳指导+复测**。
- 喂养 <8 次/日、白陶土色大便（危急转诊）、脐带渗血/化脓、嗜睡、产妇情绪低落/异常、伤口红肿渗液、家庭照护薄弱等均参与分级；设备故障手工记录强制复测提醒。
- **情绪关怀敏感项**：自伤想法「持续」→危急、「偶有」→高；EPDS ≥13→高、≥10→中；持续哭泣/严重失眠→中。敏感明细只进情绪关怀记录，flags/advice 仅出通用提示。
- 结论输出：风险等级（低/中/高/危急）+ 是否复查/转诊/母乳指导/电话随访 + 自动生成护理建议（家属端可见，护士可修改）。

## 主要 API

`POST /api/auth/login` · `GET /api/dashboard` · `GET/POST /api/appointments`（`/reschedule`、`/no-show`）· `GET /api/archives`（filter: unvisited/jaundice/maternal/unclosed）· `GET /api/archives/:id`（护士/医生含情绪关怀全量，家属自动脱敏）· `POST /api/visits`（`/assess` 预评估，支持 `mood_care` 敏感建档）· `POST /api/sync/visits`（离线幂等同步）· `GET /api/followups`（`/close`、`/decide`，决策含心理咨询/转妇保门诊）· **`GET/POST /api/mood-cares`**（护士/医生）· **`POST /api/mood-cares/family-report`**（家属代填）· **`POST /api/mood-cares/:id/actions|tracks|close`**（安排/回访/闭环）· `GET /api/family/overview`（含脱敏 `moodCare` 提醒与本人代填记录）· `POST /api/documents` · `POST /api/consults`（`/reply`）
